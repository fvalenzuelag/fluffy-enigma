# fluffy-enigma

Aplicación **Spring Boot** (API de cartas) en la carpeta `java/`.

## Inicio rápido

Entra en `java/` y sigue las instrucciones de [java/README.md](java/README.md): allí están Maven, Docker, `docker-compose` y la configuración de la base de datos.

## Docker y la nube

Los Dockerfiles y el compose del proyecto viven bajo `java/`. Comandos de referencia para **ECR** en [ecr-ubuntu.md](ecr-ubuntu.md). CI/CD en [`.github/workflows/cartas-backend.yml`](.github/workflows/cartas-backend.yml) (secretos en [`.env.example`](.env.example)).
